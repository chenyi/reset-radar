## 保留的边界

原文归档、作者引用及社区注释按原始材料展示；译文使用独立表，原帖散列变化后旧译文失效。AI 翻译可能有措辞偏差，保留逐条核对原文的入口。备选页面的通知内容是静态样式示意。
