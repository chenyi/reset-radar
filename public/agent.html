重置雷达 · AI agent 接入

本地 coding agent 使用独立 Rust CLI 和 Codex Skill 查询公开重置预告、完成公告与原帖。支持 macOS ARM64、Linux x86_64，无需安装 Python、Rust 或 Node.js。

安装 CLI 和 Codex Skill

让你的 agent 阅读本页并完成安装与验证，或在终端执行：

curl -fsSL https://radar.shadowearth.cn/downloads/install.sh | sh -s -- --agent codex && export PATH="$HOME/.local/bin:$PATH"

这一整行会安装 CLI 和 Codex Skill，并让当前终端立即可用。安装器自动为 bash、zsh 配置后续终端的 PATH，修改前备份已有配置，重复安装不会重复追加；zsh 遵循 ZDOTDIR，bash 遵循现有登录配置文件的优先级。其他 shell 会给出提示，不修改其配置。

reset-radar --version
reset-radar status --json
reset-radar skill status --json

CLI 位于 $HOME/.local/bin/reset-radar，Skill 位于 $HOME/.agents/skills/reset-radar。用新的 Codex 会话说：“用重置雷达看看最近有没有重置预告。”

管道中的脚本无法改变父终端环境，因此安装命令末尾的 export 负责当前终端立即生效；只运行脚本时，新开终端也会自动生效，当前终端仍可使用 CLI 完整路径。配置备份位于原文件旁的 文件名.reset-radar-backup.*。

查询

reset-radar status
reset-radar status --json
reset-radar events list --since 7d --type reset --json
reset-radar events get <event-id> --json

可以问：“现在有没有新的重置预告？”“最近一次重置是什么时候宣布完成的？”“这次预告有没有改期，依据是什么？”

完成公告时间与实际发生时间分别展示。来源过期或分析尚未跟上时明确说明未知；截止时间经过不表示完成。公开消息无法证明你的个人额度到账。

更新与 Skill 管理

reset-radar update --check --json
reset-radar update
reset-radar update --version 0.1.0
reset-radar skill install --agent codex
reset-radar skill status --json
reset-radar skill update
reset-radar skill remove

update 同步升级 CLI 和已经由它安装的 Skill，没有 Skill 时不会自动新增。指定旧版本可回退。skill update 同步当前 CLI 配套版本；升级整套工具用 update。本地修改或同名文件冲突时停止覆盖。

下载来源与 API

域名和 GitHub Releases 托管同一批文件，按 SHA-256 校验。可使用 --download-source site、github 或默认 auto。CLI 标签为 cli-v*，与网站发布版本分别管理。

固定版本下载目录为 https://radar.shadowearth.cn/downloads/cli-v<版本>/，包含 install.sh、平台归档、release-manifest.json、reset-radar-skill.tar.gz 和 SHA256SUMS。固定版本安装器默认安装该版本，支持 --version 版本 显式选择。

CLI 提供三个只读查询：/api/v1/status、/api/v1/events、/api/v1/events/{id}。OpenAPI · 源码与说明 · 返回首页
